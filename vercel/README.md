# QRShare — Vercel front door

QRShare is a **server-rendered Flask application**. Its HTML, CSRF tokens and
per-request CSP nonces are generated by the backend on every request, so the
application itself runs on Render and cannot be split into a static bundle
without rewriting the UI and discarding those protections.

This directory is therefore a small static entry point: it gives QRShare a
public Vercel URL that forwards visitors to the running application.

## Deploying

In the Vercel project settings:

| Setting | Value |
|---|---|
| Framework preset | Other |
| Root directory | `vercel` |
| Build command | *(none)* |
| Output directory | `.` |
| Install command | *(none)* |

## Changing the backend URL

`index.html` contains the backend URL in four places (meta refresh, canonical
link, two anchors and the script). Replace every occurrence of the existing
Render URL and redeploy.
